# Reporting API

## Overview

The Reporting API provides endpoints for generating, scheduling, and managing various types of reports. It supports multiple report formats and types, including event reports, vendor reports, booking reports, system reports, financial reports, and analytics reports.

## Base URL

```
/api/v1/reports
```

## Authentication

All endpoints require authentication using a JWT token. Include the token in the Authorization header:

```
Authorization: Bearer <your_jwt_token>
```

## Endpoints

### Create Report

Create a new report.

```
POST /
```

**Request Body**
```json
{
  "name": "Event Revenue Report",
  "type": "event",
  "format": "excel",
  "parameters": {
    "includeDetails": true,
    "groupBy": "category"
  },
  "filters": {
    "dateRange": {
      "start": "2024-01-01",
      "end": "2024-03-31"
    },
    "categories": ["wedding", "corporate"],
    "status": ["completed"]
  }
}
```

**Response**
```json
{
  "status": "success",
  "data": {
    "_id": "report_id",
    "name": "Event Revenue Report",
    "type": "event",
    "format": "excel",
    "status": "pending",
    "parameters": {
      "includeDetails": true,
      "groupBy": "category"
    },
    "filters": {
      "dateRange": {
        "start": "2024-01-01",
        "end": "2024-03-31"
      },
      "categories": ["wedding", "corporate"],
      "status": ["completed"]
    },
    "generatedBy": "user_id",
    "timestamps": {
      "created": "2024-03-20T10:00:00Z"
    }
  }
}
```

### Get Report

Retrieve a report by ID.

```
GET /:reportId
```

**Response**
```json
{
  "status": "success",
  "data": {
    "_id": "report_id",
    "name": "Event Revenue Report",
    "type": "event",
    "format": "excel",
    "status": "completed",
    "url": "reports/report_file.xlsx",
    "metadata": {
      "recordCount": 100,
      "processingTime": 5000,
      "fileSize": 1024000
    },
    "timestamps": {
      "created": "2024-03-20T10:00:00Z",
      "processed": "2024-03-20T10:00:05Z",
      "completed": "2024-03-20T10:00:10Z"
    }
  }
}
```

### Get User Reports

Retrieve reports generated by the authenticated user.

```
GET /
```

**Query Parameters**
- type: Filter by report type (optional)
- status: Filter by report status (optional)
- limit: Number of reports to return (default: 50)
- skip: Number of reports to skip (default: 0)

**Response**
```json
{
  "status": "success",
  "data": [
    {
      "_id": "report_id",
      "name": "Event Revenue Report",
      "type": "event",
      "format": "excel",
      "status": "completed",
      "url": "reports/report_file.xlsx",
      "metadata": {
        "recordCount": 100,
        "processingTime": 5000,
        "fileSize": 1024000
      },
      "timestamps": {
        "created": "2024-03-20T10:00:00Z",
        "processed": "2024-03-20T10:00:05Z",
        "completed": "2024-03-20T10:00:10Z"
      }
    }
  ]
}
```

### Schedule Report

Schedule a report for periodic generation.

```
POST /:reportId/schedule
```

**Request Body**
```json
{
  "frequency": "weekly",
  "recipients": ["user_id1", "user_id2"]
}
```

**Response**
```json
{
  "status": "success",
  "data": {
    "_id": "report_id",
    "schedule": {
      "isScheduled": true,
      "frequency": "weekly",
      "nextRun": "2024-03-27T10:00:00Z",
      "lastRun": "2024-03-20T10:00:00Z",
      "recipients": ["user_id1", "user_id2"]
    }
  }
}
```

### Cancel Scheduled Report

Cancel a scheduled report.

```
DELETE /:reportId/schedule
```

**Response**
```json
{
  "status": "success",
  "data": {
    "_id": "report_id",
    "schedule": {
      "isScheduled": false,
      "nextRun": null
    }
  }
}
```

### Download Report

Download a generated report file.

```
GET /:reportId/download
```

**Response**
- File download with appropriate content type based on report format

## Example Usage

### Create Event Report
```javascript
const response = await fetch('/api/v1/reports', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${token}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    name: 'Event Revenue Report',
    type: 'event',
    format: 'excel',
    parameters: {
      includeDetails: true,
      groupBy: 'category'
    },
    filters: {
      dateRange: {
        start: '2024-01-01',
        end: '2024-03-31'
      },
      categories: ['wedding', 'corporate'],
      status: ['completed']
    }
  })
});

const result = await response.json();
```

### Schedule Weekly Report
```javascript
const response = await fetch(`/api/v1/reports/${reportId}/schedule`, {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${token}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    frequency: 'weekly',
    recipients: ['user_id1', 'user_id2']
  })
});

const result = await response.json();
```

### Download Report
```javascript
const response = await fetch(`/api/v1/reports/${reportId}/download`, {
  headers: {
    'Authorization': `Bearer ${token}`
  }
});

const blob = await response.blob();
const url = window.URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url;
a.download = 'report.xlsx';
a.click();
```
